# J.A.R.V.I.S. downloads

A personal voice assistant for your computer. This repository holds only the ready-to-run downloads; it has no source code.

## Install (Linux, and macOS with the text console)

```sh
curl -fsSL https://github.com/MrinallSamal-byte/jarvis-releases/releases/latest/download/install.sh | sh
```

The installer asks before each step that downloads or changes anything, and checks every download against its checksum.

Each download is listed under [Releases](https://github.com/MrinallSamal-byte/jarvis-releases/releases).
